01 / THE METHOD

A workflow, not a
magic button.

Decompiler output is a hypothesis. The skill starts with evidence, chooses the layer that actually contains the app, and tells the agent when to cross-check.

01
⌁

Fingerprint before choosing

App era, compiler, splits, obfuscation, and framework determine the toolchain. The skill makes that decision explicit.

classesN.dexlib/*.soassets/resources.arsc
02
⌘

Inspect the right layer

DEX for Kotlin/Java. Native artifacts for Flutter or IL2CPP. Embedded bundles for React Native.

03
◇

Cross-check, then report

When source output looks wrong, compare engines and return to smali—the closest static ground truth.

02 / DECISION PATHS

Follow the payload.

The package extension is only the container. APKDecomp routes analysis according to where behavior is implemented.

03 / OPERATING BOUNDARY

Careful by design.

Reverse engineering is dual-use. The skill keeps authorization visible and refuses workflows aimed at piracy, DRM bypass, or unauthorized tampering.

Read the responsible-use policy →
